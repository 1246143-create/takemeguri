# 竹めぐり

**～切って、食べて、作って、買って、竹林をめぐらせる～**

徳島県阿南市の放置竹林問題に取り組むWebアプリのプロトタイプです（GCON2026 発表用）。
竹林の持ち主と市民をつなぎ、竹に興味がない人にも「竹に触れる・使う・買う」きっかけをつくります。

▶ デモ: https://1246143-create.github.io/takemeguri/

## 循環のしくみ

イベント参加 → 竹を伐採 → 竹を活用 → 商品化 → アプリで販売 → 購入 → 竹の需要が生まれる → 竹林整備

## 主な画面

| 画面 | 内容 |
| --- | --- |
| ホーム | コンセプト、開催予定のイベント、4つの関わり方 |
| イベント一覧・詳細 | 季節ごとのイベント（冬の伐採、春の筍・メンマ、乾燥後の竹細工、通年の竹炭・竹チップ） |
| 申し込み | やってみたい役割を選ぶ（体力めやす付き） → 参加者情報 → 完了（竹IDを発行） |
| わたしの竹 | 自分が伐った竹が「乾燥中 → 竹炭に加工 → 販売中」とどうなったかを追える |
| 竹の加工・活用 | 7段階の循環図 |
| ショップ | 竹炭・竹チップ・竹製品・竹細工・メンマ（購入はデモ表示のみ） |
| 竹めぐりとは | 放置竹林の課題をイラストで説明 |

## 技術

- React 18（CDN） + Babel Standalone の1ファイル構成（`index.html`）。ビルド不要
- データはすべてダミー。決済機能はありません
- コードは「データ → ルーター → アイコン・イラスト → 共通部品 → ページ」の順に整理。イベントや商品は `EVENTS` / `PRODUCTS` 配列に追加するだけで増やせます

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます（インターネット接続が必要です）。
